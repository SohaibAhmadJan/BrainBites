# Version Snapshot: v2.7.4 (Universal Accessibility & Goals)

This document serves as the official record of **Version 2.7.4** of the BrainBites application. This version focuses on bringing deep customization and inclusivity to the user experience through universal text scaling and personalized learning goals.

## Key Features in v2.7.4

### 1. Universal Text Scaling
- **Theme-Level Integration**: Moved scaling logic directly into the app's core theme. All text elements (headings, body, labels, buttons) now scale proportionally based on a single user setting.
- **Dynamic Proportionality**: Ensures that a 20% increase in body text is matched by a 20% increase in headings, maintaining the intended visual hierarchy at any size.
- **App-Wide Impact**: Instantly affects every screen, from the home hub to deep fact details and notification lists.

### 2. Personalized Learning Goals
- **Daily Target Setting**: Users can now set a daily reading goal (3, 5, 10, or 20 facts) to track their personal learning journey.
- **Persistent Preferences**: Goals are saved locally and persist across app restarts, laying the foundation for future progress-tracking features.

### 3. Tactile & Visual Polish
- **Haptic Feedback Toggle**: Introduced a system-wide haptic feedback setting, allowing users to enable or disable tactile vibrations for key interactions like favoriting facts.
- **Enhanced Settings UI**: Reorganized the Settings screen into logical sections: General, Personalized Goals, Appearance & Accessibility, and App info.
- **Functional Integrity**: Replaced all placeholder settings with fully functional, reactive components backed by a new `PreferenceManager`.

### 4. Versions Available
- **Version 1.0 - 2.6**: Foundational growth and Explore Hub evolution.
- **Version 2.7.1**: Visual Discovery & Dynamic Gradients.
- **Version 2.7.3**: Unified Navigation Transitions.
- **Version 2.7.4**: (CURRENT) Universal Accessibility & Goals.
