# Version Snapshot: v2.8.7 (Curated Discovery & Smart Sharing)

This document serves as the official record of **Version 2.8.7** of the BrainBites application. This version marks a major evolution in how users discover psychological insights and share them with the world.

## Key Features in v2.8.7

### 1. Search 2.0 (Deep Discovery)
- **Deep-Content Indexing**: The search system now indexes hidden keywords, categories, and full fact text.
- **Tokenized Matching**: Support for multi-word queries (e.g., "social help") to find exactly what you're looking for.
- **Smart Empty States**: Helpful suggestions and "Surprise Me" actions when no results are found.

### 2. Smart Sharing (Visual Quote Cards)
- **Branded Quote Cards**: Users can now share high-quality, 1080x1080 images of psychology facts.
- **Dynamic Theming**: Share cards automatically use gradients and colors based on the fact's category.
- **Branding Integration**: Every shared card features the BrainBites logo and tagline ("Feed Your Mind Daily").

### 3. Collection Sets (Curated Paths)
- **Thematic Kits**: Introduced curated learning paths like "The Persuasion Kit" and "Social Mastery".
- **Mastery Tracking**: Real-time progress bars for each collection, celebrating completion with "Mastered" badges.
- **Unified UI**: Perfectly aligned headers and navigation for a distraction-free learning experience.
