# Tools and Techniques: BrainBites Ecosystem

This document outlines the specific technologies, frameworks, and tools utilized across the BrainBites mobile application (iOS & Android), Web Admin Panel, and Serverless Backend.

| Category | Tools/Techniques |
| :--- | :--- |
| **Programming Languages** | Dart (Flutter), TypeScript, JavaScript (Node.js) |
| **Frontend Framework (Mobile)** | Flutter SDK (Cross-platform iOS & Android), Material/Cupertino Widgets |
| **Frontend Framework (Web)** | React.js, Vite, Tailwind CSS, Framer Motion (Animations) |
| **Backend & Serverless** | Firebase Cloud Functions, Vercel Node.js Serverless Functions |
| **Databases** | Cloud Firestore (NoSQL real-time document database) |
| **Authentication & Identity** | Firebase Authentication, Custom JWT Tokens, 6-Digit Email OTP |
| **External Integration APIs** | Cloudinary REST API (Media hosting), Gmail SMTP / Nodemailer (Email dispatch), LoremFlickr / Unsplash (Dynamic images) |
| **State Management & Concurrency**| Provider / Riverpod / BLoC (Flutter), React Hooks (Web) |
| **Image Loading & Processing** | cached_network_image (Flutter) |
| **Version Control & DevOps** | Git, GitHub |
| **Hosting & Deployment** | Vercel (Admin Panel & Backend API Hosting) |
| **Build Tools** | Flutter CLI, Gradle (Android), CocoaPods (iOS), npm (Node Package Manager) |
| **IDE / Editors** | Visual Studio Code (VS Code) |
| **Architecture Patterns** | MVVM / Clean Architecture, Repository Pattern |
| **Testing** | Flutter Test, Jest (Admin Panel), Postman (APIs), Cypress (E2E) |
| **Documentation & Design** | MS Word, draw.io, Figma |
| **Methodology** | Agile (Iterative two-week sprints) |
| **Reporting & Diagnostics** | Firebase Crashlytics, custom console logging |
